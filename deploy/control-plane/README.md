# Control Plane deployment

This deployment installs the portable Control Plane role: Docker Compose, data
volumes, authenticated MQTT, PostgreSQL, Control Plane services, and the
loopback Dashboard. The Pi-only USB services are an explicit optional profile.

Read [INSTALL.md](INSTALL.md) for first deployment, [UPDATE.md](UPDATE.md) for
an in-place update, [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for diagnostics,
and [MIGRATE.md](MIGRATE.md) for replacing the Control Plane.
